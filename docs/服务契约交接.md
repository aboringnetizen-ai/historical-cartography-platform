# Phase 0 服务契约交接

共享契约使用 `@historical-cartography/shared-schema`。Schema v4.0 原字段在 [canonical.ts](../packages/shared-schema/src/canonical.ts)。新增的[服务读模型](../packages/shared-schema/src/service-contracts.ts)只描述服务边界，原数据契约指纹保持不变。

## 给 Gemini

用 [类型检查覆盖的地图样例](../packages/shared-schema/examples/service-examples.ts)搭建地图组件。输入为 `MapSnapshotRequest`，含明确的修订 ID 和历史 JDN。纪元区间为左闭右开。地图响应包含 `epoch`、`revision_id`、`data_status`、面和共享边界。面使用统一的 `control_score`，纯疆域与控制力切换可以使用同一个快照。外侧无限面用 `null` 表示。GeoJSON Polygon 是由拓扑派生的只读渲染数据。正式编辑提交通过空间操作接口。

样例为人工绘制的测试数据。前端清楚显示草稿状态，可用它验证请求、渲染和图层切换。正式地图快照、地名、政区和历史事件接口在空间与史料服务联通后扩展。具体传输方式在相应任务中和生产方确认。

`backend/core` 分支已有真实 PostGIS 草稿快照实现。可通过[拓扑包入口](../packages/topo-core/src/index.ts)和[本地运行说明](../packages/topo-core/README.md)接入。共享弧段可附带当前纪元的 `snapped_paleo_feature_id`。该可选字段属于服务读模型。

## 给后端 AI 2

实现面向 Codex 的 `EventEvidenceReader.verifyEvent`。请求可用 `event_revision` 固定证据核验版本。返回 `VERIFIED` 时提供实际事件、事件修订以及每条核验引文所属的文档与索引修订。返回 `PENDING_REVIEW` 或 `REJECTED` 时提供结构化门禁结果，并尽量定位到事件或引文。类型检查覆盖[待核验和引文失败样例](../packages/shared-schema/examples/service-examples.ts)。

`VERIFIED` 指服务已经核对引文。正式疆域提交仍由事务服务执行信源等级、事件关联、证据版本和人工审阅门禁。正例请用实际原文样本生成，让相关 Agent 可以复查页码、行号与内容。

## 变更集草稿

`OpenMapChangeSetRequest` 包含前端或 MCP 客户端生成的 `changeset_id`（UUID）、目标纪元、底图修订、分支和事件 ID。服务端使用可信的操作者身份，并调用史料服务核验。成功结果带草稿和固定的事件版本、引文 ID、来源文档 ID、原文索引版本。网络失败后复用相同 UUID 与相同载荷，可以读取已经保存的草稿。更改载荷时使用新 UUID。

无事件、错纪元、引文定位或内容不一致均拒绝创建。只有低等级线索或存在 T1 争议的草稿进入 `PENDING_HUMAN_REVIEW`。`recheckMapChangeEvidence` 拉取最新可信事件并对照固定的事件和索引版本。漂移时报告拦截原因，原草稿保留原来的证据版本。

`ReassignBaseUnitsRequest` 使用打开的变更集、此次操作 UUID、当前草稿修订、逐项归属／控制分和已绑定事件。成功响应给出新修订及其受影响的面、弧段和事件。重连时可用 `readMapChangeDraft` 查询活动修订及操作记录。确认回滚当前草稿操作后，活动修订指回适用的上一版本。

Gemini 的 [HTTP 客户端](../../AI赋能-frontend-studio/packages/carto-studio-web/src/core/services/snapshot-client.ts)目前把 `/api/v4/map-snapshots/query` 解码成含朝代、人物、政区、证据等数据的 `EpochSceneBundle`。空间内核输出的是 `MapSnapshot`。联调时先对齐共用的场景响应结构，从真实版本读取附属资料。只读拓扑快照、证据核验、草稿与正式发布的状态各有独立入口。

## 928 年真实史料验收

目前数据库集成测试采用人工工程几何和引文服务响应样例。真实 A-40 需要来源原件、版本、页行定位、实际核验结果和可审查的地点归属。可先核对《塔巴里斯坦史》Browne 节译中阿斯法尔攻占塔巴里斯坦的部分（原稿标注 f. 137a），再核对马尔达维季击败阿斯法尔的段落（f. 138）。后者在该译本中记为伊斯兰历 319 年／公元 931 年。[原文节译](https://persian.packhum.org/text/009801020/3)

关于齐亚尔政权的起点，TDV 条目提出 316 年／928 年并列举其他纪年，Iranica 的齐亚尔条目采用 931 年。事件登记时分别核对宣告独立、掌握具体地点与击败阿斯法尔的日期；未解决的年代、政权归属和疆界留在待核验或争议流程。史料方交付至少一个独立可复查的正例与相应错页或伪引文反例，再由集成端运行正式证据验收。[TDV 齐亚尔条目](https://islamansiklopedisi.org.tr/ziyariler) · [Iranica 齐亚尔条目](https://www.iranicaonline.org/articles/ziyarids/)
